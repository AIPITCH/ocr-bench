Изображение 87. Гнездо каркаса с движком невосводимого взрывателя.
1-шток пиротехнического стопора
Самolikвидатор (см. изображение 88) представляет собой алюминиевую
втулку в фигурный канал которой запрессован пиротехнический замедлитель с
длительностью горения примерно 2,2 минуты. Самolikвидатор устанавливается в
вертикальное гнездо каркаса. Заряд пиротехнической смеси самolikвидатора
инициируется электроподжигателем ЕА1. В конце дорожки пиротехнической
смеси самolikвидатора расположена запрессовка пиротехнического усилителя,
предназначенная для инициирования капсюля-детонатора в движке взведенного
взрывателя.
Изображение 88. Каркас с обословленным самolikвидатором.
1-отверствие воспламенения самolikвидатора форсом огня от электроподжигателя ЕА1,
2-отверствие передачи форса огня от самolikвидатора на капсюль-детонатор в движке,
3-самolikвидатор, 4-гайка гнезда самolikвидатора, 5-прокладка, 6-запрессовка
пиротехнического усилителя.
Двигатель с капсюлем-детонатором лучевого действия (см. 89, 90)
расположен в горизонтальном канале каркаса. Двигатель имеет гнездо с
капсюлем-детонатором лучевого действия, отверстие для штока соленоида, канал
для пружины движка, гнездо для штока кнопки, канавку для фиксатора движка.
При взведении взрывателя движок перемещается пружиной в боевое положение и
фиксируется в этом положении фиксатором движка (см. рисунок 91).

Изображение 87. Гнездо каркаса с движком невозводимого взрывателя. I-шток пиротехнического стопора
Самоликвидатор (см. изображение 88) представляет собой аллюминиевую втулку в фигурный канал которой запрессован пиротехнический замедлитель с длительностью горения примерно 2.2 минуты. В конце дорожки пиротехнической смеси самоликвидатора расположена запрессовка пиротехнического усилителя, предназначенная для инициирования капсюля-детонатора в движке введенного взрывателя.
Изображение 88. Двигатель имеет гнездо с капсюлем-детонатором лучевого действия, отверстие для штока соленоида, канал для пружины движка, гнездо для штока кнопки, канавку для фиксатора движка. При введении взрывателя движок перемещается пружиной в боевое положение и фиксируется в этом положении фиксатором движка (см. рисунок 91).
